Méthode de calcul, références et limites +

Modèle mécanique

Le solveur résout le problème de Burmister : couches élastiques linéaires, homogènes et isotropes, d’extension latérale infinie, reposant sur un massif semi-infini. La solution est exprimée par transformée de Hankel ; pour chaque valeur du paramètre d’intégration, les coefficients des couches sont obtenus par résolution directe des conditions aux limites : charge en surface, continuité des contraintes et des déplacements aux interfaces collées, cisaillement nul de part et d’autre des interfaces glissantes. Les intégrales sont évaluées par quadrature de Gauss-Legendre entre les zéros des fonctions de Bessel. Le jumelage est obtenu par superposition de deux charges circulaires ; une interface semi-collée est la moyenne des calculs collé et glissé, comme dans Alizé-LCPC.

Référentiel LBTP 2024 (Côte d’Ivoire)

Hypothèses : θéq = 32 °C, f = 20 Hz ; ν = 0,45 (bitumineux), 0,35 (autres) ; essieu 130 kN ; durée 20 ans (autoroute, route UEMOA, RN à plus de 200 PL/j/sens), 15 ans sinon.
NE = 365 · MJA · C · CAM ; C = n·[1 + (n−1)·τ/2] ; dimensionnement à la borne supérieure de la classe TC1⁻ … TC6⁺.
Bitumineux : εt,adm = ε6 · (NE/10⁶)^b · kθ · kr · ks · kc ; kr = 10^(−u·b·δ) ; δ = √(SN² + (c·Sh/b)²) ; c = 2 m⁻¹
Sh = 0,01 m (h ≤ 0,10 m) ; 0,01 + 0,3·(h − 0,10) (0,10 < h ≤ 0,15 m) ; 0,025 m (h > 0,15 m)
ks = 1/1,2 (E < 50) ; 1/1,1 (50 ≤ E < 80) ; 1/1,065 (80 ≤ E < 120) ; 1 (E ≥ 120 MPa) ; risque r : 30 / 25 / 15 / 10 / 5 / 5 % de TC1 à TC6
Plateforme : εz ≤ 0,020·NE^(−0,222) (assise non traitée) ; 1,20·εz ≤ 0,020·NE^(−0,222) (assise améliorée au ciment, ka = 1,20) ; εz ≤ A·NE^(−0,222), A = 0,016 / 0,014 / 0,013 (assise bitumineuse, TC1-2 / TC3-4 / TC5-6)
Non traités et améliorés Q1 : découpage en sous-couches de 25 cm au plus, E = min(k · E sous-jacent ; Emax)

Méthode rationnelle NF P 98-086 (calcul libre)

Enrobés : εt,adm = ε6(10 °C, 25 Hz) · (NE/10⁶)^b · √(E(10 °C)/E(θéq)) · kr · ks · kc
Matériaux traités aux liants hydrauliques : σt,adm = σ6 · (NE/10⁶)^b · kr · kd · ks · kc
Sols et matériaux non traités : εz,adm = A · NE^(−0,222)
