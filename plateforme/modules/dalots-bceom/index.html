Méthode de calcul, hypothèses et limites +

Équations de l’hydraulique routière BCEOM

L’outil résout les équations du manuel Hydraulique Routière (Nguyen Van Tuu, BCEOM, 1981) pour les dalots rectangulaires à sortie libre, en régime permanent, avec partage égal du débit entre cellules identiques.

Débit réduit en amont

Chaque cellule reçoit le débit q = Q / N. Le débit réduit caractérise la charge hydraulique à l’entrée :

Q*H₁ = q / ( B · D · √(2gD) )

Hauteur d’eau amont

Le rapport H₁/D est obtenu par numérisation de l’abaque BCEOM (figure 77 du manuel), sous la forme d’un polynôme de degré 6 ajusté sur le domaine d’emploi :

H₁/D = −2,6213·z⁶ + 12,192·z⁵ − 23,291·z⁴ + 23,261·z³ − 10,876·z² + 4,3291·z + 0,0631

où z = Q*H₁. La hauteur réelle est ensuite H₁ = (H₁/D) · D.

Pente critique

Le débit réduit critique est calculé pour chaque section et chaque débit :

Q*Ic = q / √( g · B⁵ )

La pente critique réduite est obtenue analytiquement :

Ic* = (Q*Ic)^(2/3) · [ 2 + (1/Q*Ic)^(2/3) ]^(4/3)

La pente critique réelle vaut :

Ic = Ic* · g / ( Ks² · B^(1/3) )

Vitesse et tirant d’eau uniformes

Le débit réduit vitesse est :

Q*V = q / ( Ks · √I · B^(8/3) )

Le rapport X = y/B est solution de l’équation de Manning réduite :

X^(5/3) / ( 1 + 2X )^(2/3) = Q*V

résolue par dichotomie. La vitesse réduite vaut V* = [ X / (1 + 2X) ]^(2/3), puis :

V = V* · Ks · √I · B^(2/3) ,    y = X · B

Hypothèses et limites

Présélection à écoulement permanent, cellules rectangulaires identiques, répartition égale du débit, sortie aval libre. Le polynôme H₁/D est une numérisation de l’abaque BCEOM : sa précision n’est garantie qu’à l’intérieur du domaine d’emploi de la figure 77 (0,19 ≤ Q*H₁ ≤ 0,44 environ). Toute valeur hors de ce domaine est signalée comme extrapolation.

À vérifier au projet : niveau aval et remous, pente construite, conditions d’entrée, crue de vérification, revanche sous chaussée, affouillement, embâcles, dépôts, dissipation d’énergie et dimensionnement structurel. Le pourcentage y/D ne représente pas une revanche sous chaussée.

Cet outil est un outil de présélection. Il ne remplace pas un calcul de ligne d’eau ni une vérification par un modèle numérique de référence.
